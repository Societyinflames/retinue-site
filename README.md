# retinueengine.com

The public website for Retinue Engine, a solo story-game engine that runs inside your own Claude app.

- `index.html`: the home page (built from the source in the private build repo).
- `assets/`: images, favicon and app icon.
- `download/Retinue.html`: the game loader players publish in their own Claude. It loads `retinue-engine` from npm via jsDelivr.

Hosted on GitHub Pages. Nothing private (no Ashfall content) belongs in this repo.
